# Source Code

This folder contains the computational tools and interactive
demonstrations developed for the "Seeing Through the Atmosphere"
project.

Planned components include:

- Synthetic atmospheric spectral modeling
- Interactive spectral-band selection
- Five-band optimization demonstration
- Noise and robustness simulations
- Classification demonstrations
- Physics-informed remote-sensing visualizations

The public demonstrations use educational or simulated data and do
not contain unpublished research datasets or restricted materials.
