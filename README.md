# Seeing Through the Atmosphere

**An interactive science communication project exploring atmospheric remote sensing, spectral optimization, and physics-informed machine learning.**

This project is being developed as part of the URA STEM Ambassador Challenge.

## Project Overview

Earth-observing sensors do not measure Earth's surface in isolation. Electromagnetic radiation interacts with the atmosphere through processes such as absorption and scattering before reaching a remote-sensing instrument.

**Seeing Through the Atmosphere** explores how physics and computational methods can help scientists extract useful information from these measurements.

The project will combine:

- An interactive educational demonstration of spectral-band selection and optimization
- Atmospheric remote-sensing physics
- Simulated spectral data
- Computational optimization and noise analysis
- A science communication exploration of physics-informed machine learning research at Pacific Northwest National Laboratory (PNNL)
