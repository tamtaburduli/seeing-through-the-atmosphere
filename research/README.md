seeing-through-the-atmosphere
An interactive science communication project exploring how physics-informed AI can improve atmospheric correction in remote sensing

Research Notes
This folder contains background research and source notes for the "Seeing Through the Atmosphere" project.

The project explores how atmospheric physics, spectral information, computational optimization, and physics-informed machine learning can be used to improve the interpretation of remote-sensing measurements.

Main Scientific Themes
Atmospheric absorption and scattering
Remote sensing and spectroscopy
Spectral-band selection
Physics-informed machine learning
Atmospheric correction
Environmental and Earth-observation applications
Research Inspiration
The science communication portion of this project is inspired by research from Pacific Northwest National Laboratory (PNNL) on physics-informed machine learning for atmospheric correction.

A separate interactive educational demonstration will illustrate spectral-band selection and optimization concepts related to passive atmospheric remote sensing.
